# Malaysia ADM1 Boundary Attribution

- Dataset: geoBoundaries Malaysia ADM1 (boundary ID `MYS-ADM1-15666254`)
- Boundary year represented: 2017
- Source: OpenStreetMap / Wambacher
- Provider: geoBoundaries, William & Mary geoLab
- License: Open Data Commons Open Database License (ODbL) 1.0
- Metadata: https://www.geoboundaries.org/api/current/gbOpen/MYS/ADM1/
- Project: https://www.geoboundaries.org/

The application uses the simplified GeoJSON distribution and maps `Malacca` to `Melaka` and `Penang` to `Pulau Pinang`. Federal Territories are omitted because the current application dataset covers 13 states.
